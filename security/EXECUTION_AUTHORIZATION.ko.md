# 링커엑스 보안 후속 실행 범위 — 2026-11-17

사용자는 대화에서 "승인요청하지 않고 실제로 성공해서 둘이서 보안문제 해결까지 그냥 완료해죠 내가 관여하지 않고 이후 작업은 승인한걸로 간주할께"라고 지시했습니다.

기존의 단계별 추가 승인 요청 문구는 이 후속 승인에 맞춰 적용합니다. 보안 코드 수정, 검증, 자동 실행 연결 보완, 필요한 검토 PR 반영을 계속 진행합니다. 이번 대화에서 자동 실행 PR #2~후속 수정 PR을 반영했습니다. 개별 수정마다 같은 승인을 다시 요청하지 않습니다.

범위는 링커엑스 두 저장소의 인증·권한·회사 격리·사용량 정확도 및 이를 위한 두 도구의 실행 연결입니다. 별도 PWA 관제 앱 기획은 사용자가 보류했습니다. 기존 재고·상차·전표 작업은 충돌 조사/회귀 검증으로 보호하고 관련 계산 로직을 임의로 재작성하지 않습니다.

운영 공개 규칙 복원은 해결 방법으로 사용하지 않습니다. 테스트는 demo-linker-auth를 사용하고 생산 복구는 검증 결과와 실제 소속 확인을 바탕으로 수행합니다. 결제수단 입력, 약관 동의 및 소유자 본인이 해야 하는 인증은 에이전트가 대신 완료했다고 처리하지 않습니다. 플랫폼 최초 UID/기존 업무 계정 소유 관계를 추정하거나 이메일 일치로 자동 연결하지 않습니다.

현재 확인한 실제 장애물은 Firebase Spark 요금제입니다. 작성된 Cloud Functions 서버를 배포하려면 결제 연결이 필요합니다. 운영 계정 Google 로그인과 실제 메일 수신은 아직 완료되지 않았습니다. 미완료 항목을 PASS 또는 운영 복구 완료로 표시하지 않습니다.

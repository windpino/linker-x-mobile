## 현재 운영 경계

- 확인한 Firestore 운영 규칙은 전체 차단입니다. 공개 규칙은 복원하지 않았습니다. 운영 업무 접근은 아직 재개되지 않았습니다.
- 인증 코드는 feature/firebase-auth 개발 브랜치에 있습니다. 테스트 성공이 운영 배포 완료를 뜻하지 않습니다.
- Spark 상태에서 현재 작성한 Cloud Functions를 운영 배포할 수 없습니다. 공식 근거: https://firebase.google.com/docs/functions/get-started
- 최초 플랫폼/대표 UID와 기존 회사·직원 문서의 실제 소유 관계를 확정해야 합니다. 이메일 동일만으로 연결하지 않습니다.
- 실제 Google 로그인, 실제 이메일 인증/재설정 메일 수신, 운영 기기 회귀는 미완료입니다.
- 거래처 전용 주문 투영과 입력은 검증했으나 기존 전체 회원사몰 주문→매출전표 변환 경로 전체를 완료했다고 주장하지 않습니다.
- 운영 기존 문서의 평문 비밀번호 삭제 마이그레이션은 시행하지 않았습니다. 응답·신규 저장 경로를 차단한 것과 구분합니다.
- 앱 수집량은 Firebase 전체 과금량이 아닙니다. 미수집·부분 수집·추정·실제 0을 구분하고 전체 청구량 일치를 단정하지 않습니다.
